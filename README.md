The site includes 13 coordinated product, retail and face-free lifestyle images, interactive occasion tabs and a pack-format selector.

## Pack architecture

- Single sachet: 30 g.
- Journey Cup: five sealed 30 g sachets of one flavour, 150 g total, plus one paper shell bag.
- Family Mix: one bucket, twenty sealed 30 g sachets, five of each of four flavours, 600 g total.
- Retail display: twenty-four individually saleable 30 g sachets, 720 g total.

Flavours: Classic Sea Salt, Garlic Salt, Pepper Lime and Fire Salt.

## Run and publish

This is a static site with no build step, external runtime libraries or backend. Keep the folder structure intact and open website/index.html in a browser.

GitHub Pages publishes the main branch from the repository root. The root index redirects to website/ so relative image and guide links remain portable.

## Status

This is a brand and packaging design concept, not an operational ecommerce store. Retail scenes are proposed placements, not evidence of distribution. Photography is generated concept artwork; final typography, materials, Arabic copy and converter dielines need production approval. No payment processing, live inventory or tracking system is included.
